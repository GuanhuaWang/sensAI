To generate activations given a model

1) Specify model checkpoint location in scripts/activations.sh
2) Specify channel score directory output location in scripts/activation.sh

python3 evaluate.py -a vgg19_bn --resume INSERT_CHECKPOINT_DIR/checkpoint.pt.tar --evaluate --class-index ${i} -s INSERT_LC_LOG_DIRECTORY > observe_logs/observe_${i}.log

2) Run script: sh scripts/activations.sh

Note: To specify passing inputs from test set specify --prune-test 1

python3 evaluate.py -a vgg19_bn --resume INSERT_CHECKPOINT_DIR/checkpoint.pt.tar --evaluate --class-index ${i} -s INSERT_LC_LOG_DIRECTORY --prune-test 1 > observe_logs/observe_${i}.log

Note: To specify saving full feature map data speficy --store-data INSERT_FEATURE_MAP_DIRECTORY

python3 evaluate.py -a vgg19_bn --resume INSERT_CHECKPOINT_DIR/checkpoint.pt.tar --evaluate --class-index ${i} -s INSERT_LC_LOG_DIRECTORY --prune-test 1 --store-data INSERT_FEATURE_MAP_DIRECTORY > observe_logs/observe_${i}.log
